## Experiments Included
Experiments and topics covered in this lab course include:

- Fabry–Perot Interferometer
- Faraday Effect
- Fibre Optics
- Mach–Zehnder Interferometer
- Spatial Light Modulator (SLM)
- Geometric / Pancharatnam Phase
- Polarization and Stokes Parameters

## Recommended References

- *Optics (5th Edition)* — Eugene Hecht
- *OPTICS 7TH EDITION* - Ajoy Ghatak
- *Wave Optics: Basic Concepts and Contemporary Trends* — Subhasish Dutta Gupta, Nirmalya Ghosh, Ayan Banerjee
- *Polarized Light, Revised and Expanded* - Dennis Goldstein, Dennis H. Goldstein

These references are very useful for understanding the theoretical concepts behind the experiments ✨.

---

## Useful Tip

Before performing the experiments, it is very helpful to:
- Read the manual carefully
- Understand the theoretical background
- Revise important derivations
- Prepare observation table formats beforehand

This saves a lot of time during the lab sessions 😄.
